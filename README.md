# 🎓 Student Placement Prediction

A Machine Learning project that predicts whether a student is likely to get placed based on academic and other student-related factors.

## 📌 About the Project

This project uses Machine Learning to analyze student information and predict placement outcomes.

The project includes:
- Data preprocessing
- Machine Learning model training
- Placement prediction
- Python Flask application
- Saved ML model

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML/CSS (if applicable)
